# 「寻穴 AcuPoint AR」市场调研报告

> 调研日期：2026-11-02 ｜ 版本 v1.0 ｜ 用途：MVP 产品定义依据

---

## 一、市场背景与规模

| 指标 | 数据 | 来源 |
|---|---|---|
| 中国中医养生保健市场规模 | 2023 年已超 **2200 亿元**，持续增长 | 中国报告大厅 |
| 行业扩张速度 | 2024 上半年新注册养生保健企业 21.38 万家，同比 +28.1% | 中国报告大厅 |
| 互联网医疗用户规模 | 截至 2024/12 达 **4.18 亿人**（占网民 37.7%） | CNNIC |
| 互联网医疗市场规模 | 约 4799 亿元（含医药电商） | 艾媒咨询等 |
| 目标人群结构 | 亚健康人群低龄化，**18–35 岁占比约 55%**（穴位养生场景） | 寻艾竞品分析（人人都是产品经理） |

**趋势驱动因素**
1. **政策**：中医药上升为国家战略，「治未病」方针为养生工具类产品营造了良好环境。
2. **年轻化养生潮**：三伏贴、艾灸、八段锦、经络推拿等内容在小红书/抖音持续升温；"贴穴位贴却不知道穴位在哪"是高频真实场景。
3. **技术成熟**：MediaPipe（面部 468 点 / 手部 21 点 / 姿态 33 点）等端侧模型可在浏览器实时运行，无需后端、无需上传画面。

## 二、竞品分析

### 2.1 直接竞品

| 产品 | 形态 | 核心能力 | 短板（我们的机会） |
|---|---|---|---|
| **寻艾** | iOS/Android App | AI+AR，拍照识别穴位（覆盖 449 个国标穴位）、舌诊面诊、问答社区 | 需下载安装；拍照上传→等待识别，非实时叠加；光线问题影响识别；闭源 |
| **经络穴位图解（灸大夫）** | App | 静态图谱+笔记社区，官方称数千万下载 | 纯图文对照，无摄像头实时定位，"图是图、我是我" |
| **大家中医** | App | 面向专业医师的诊疗辅助 | 面向 B 端专业人士，普通用户门槛高 |
| **Visual Acupuncture 3D / AcuPoint** | App | 3D 人体模型查穴 | 3D 模型是"别人的身体"，无法对准自己的体态 |
| **学术原型 FaceAtlasAR (2021) / E-faceatlasAR (2022)** | 论文系统 | 实时面部/耳部穴位 AR（60FPS） | 仅停留在研究阶段，未产品化、未覆盖全身 |

### 2.2 竞争格局结论

- **静态图谱赛道已饱和**（灸大夫等占据心智），**"实时摄像头找穴"赛道在消费级市场基本空白**——学术研究证明了可行性，但没有可用的消费级产品。
- 寻艾验证了「拍照识穴」需求真实存在且能作为获客亮点，但其"上传-等待"模式体验割裂；**实时取景框内直接叠加穴位**是体验代差。
- 大厂（京东健康、丁香医生）尚未进入该细分场景。

## 三、目标用户画像与核心痛点

**P0：养生实操人群（18–35 岁为主，女性偏多）**
- 场景：艾灸、穴位贴、按摩、刮痧前需要找穴
- 痛点：网文配图与自己体态对不上；"我按的地方到底是不是足三里？"
- 需求：对准镜头 → 屏幕直接告诉我"这就是足三里"

**P1：中医学习者（学生/爱好者/养生馆学徒）**
- 需求：骨度分寸取穴法可视化练习、穴位功效速查
- 需求：可截图保存学习笔记

**P2：亚健康自护人群**
- 失眠（神门/安眠）、眼疲劳（睛明/太阳）、颈椎（肩井/风池）等小毛病自助按摩

**核心痛点总结**
1. 找穴难：图文对照无法映射到自己的身体
2. 反馈缺失：不知道自己找得准不准
3. 工具重：现有多要求下载 App，安装门槛高
4. 隐私顾虑：拍身体照片上传云端令人不适

## 四、机会点 → MVP 产品定义

**差异化定位：`零安装 · 实时叠加 · 本地处理 · 开源免费` 的网页版实时找穴工具**

| 决策 | 依据 |
|---|---|
| Web（HTML5）而非原生 App | 零安装、链接即用（微信/浏览器扫码打开）；GitHub Pages 免费托管，符合"先部署于 GitHub" |
| 实时摄像头叠加，而非拍照上传 | 对竞品（寻艾）形成体验代差；MediaPipe 端侧模型可 30-60FPS 运行 |
| 首期覆盖 面部 / 手部 / 全身 三大区域 | 面部=眼疲劳失眠场景（用量大、精度高）；手部=按摩保健场景（21 个手部关键点精度极高）；全身=足三里/三阴交等大众知名度最高穴位 |
| 骨度分寸比例映射 | 不依赖训练数据标注，用中医传统"骨度分寸法"把穴位锚定在 AI 关键点上，可解释、可扩展 |
| 画面全部本地处理，不上传 | 化解隐私顾虑，亦是传播卖点 |
| 内置免责声明 | 健康类产品合规底线：定位仅供学习参考，不构成医疗建议 |

**v1 功能清单（已实现）**
1. 三种模式：面部（16 穴）/ 手部（20 穴，掌面/手背自动识别）/ 全身（24 穴，含背面提示）
2. 实时叠加：彩色经络编码圆点 + 穴位名称标签，关键穴位优先显示
3. 实时反馈：点击屏幕任意位置 → 高亮最近穴位并弹出详情（定位/功效/按摩方法）；选穴后脉冲光环引导
4. 拍照：一键合成"画面+穴位标注"截图保存
5. 穴位库：搜索（名称/拼音/代码/功效）+ 分区浏览
6. 状态引导：未检测到部位/距离太远等实时提示

**后续路线图（v2+）**
- 耳部穴位（耳穴压豆场景，学术上已验证可行）
- 经络循行线绘制（把同经穴位连成线）
- PWA 离线缓存、中英双语
- 取穴准确性数据回收与校准（用户反馈驱动）

## 五、风险与对策

| 风险 | 对策 |
|---|---|
| 穴位定位精度（比例映射存在个体差异） | 明示"约位置 + 请结合酸胀感确认"；提供定位描述文字辅助校正；后续用反馈数据校准 |
| 医疗合规 | 全程"学习参考"定位，免责声明显著展示；不做诊断/疗效承诺 |
| 微信内置浏览器兼容性 | 提供"用系统浏览器打开"引导；MediaPipe 在主流移动浏览器均可运行 |
| 模型文件体积（~20MB 首次加载） | 自托管 + 浏览器缓存；加载进度提示 |
