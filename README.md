# 寻穴 AcuPoint AR 🔍

> **把镜头对准自己，穴位直接标在你身上。**
> 零安装的网页版实时取穴工具：打开摄像头，屏幕上实时叠加穴位名称与位置，点哪讲哪，一键拍照标注。

[在线体验（GitHub Pages）](https://wegene38.github.io/acupoint-ar/) · [市场调研报告](docs/市场调研报告.md)

## ✨ 功能特性

| 功能 | 说明 |
|---|---|
| 📷 **实时找穴** | 摄像头取景 + MediaPipe 端侧 AI 关键点检测，穴位圆点与名称实时叠加在画面上 |
| 🗺️ **三大区域** | 面部 17 穴（眼疲劳/失眠/头痛场景）· 手部 22 穴（含腕与前臂）· 全身 25 穴（含背面穴位虚线提示） |
| 🖐️ **掌背自动识别** | 手部模式自动判断掌面/手背朝向，切换显示对应穴位（可手动覆盖） |
| 👆 **点哪讲哪** | 点击画面任意穴位 → 弹出定位描述、功效主治、按摩方法；选中的穴位带脉冲光环 |
| 🔍 **功效搜索** | 按"失眠 / 头痛 / 胃痛"等功效词或穴位名/拼音/国际代码搜索 |
| 📸 **拍照标注** | 一键合成"画面 + 穴位标注"截图并保存，可作学习笔记 |
| 🎨 **经络配色** | 每条经络独立配色（肺经金、心包紫、任脉粉……），圆点颜色即经络 |
| 🔒 **隐私优先** | 画面只在设备本地推理，**不经任何服务器、不存储不上传** |
| 📲 **可安装 PWA** | 添加到手机桌面，全屏运行、**离线可用**（自动缓存 App 壳与 AI 模型） |
| 🚫 **零门槛** | 纯静态网页，浏览器/微信打开即用；模型全部自托管，无第三方 CDN 依赖 |

## 🧭 技术原理

以 MediaPipe 三个人体关键点模型（面部 478 点 / 手部 21 点 / 姿态 33 点）为"骨性锚点"，
按中医**骨度分寸法**用比例关系推算穴位位置——例如：

- 合谷 = 第 2 掌骨中点桡侧（食指掌指关节与腕横纹连线中点，偏向拇指）
- 足三里 = 犊鼻下 3 寸（膝→踝距离的 3/16 处，向外 1/16）
- 太阳 = 眉梢与外眼角连线中点向后（眉梢-外眦中点向颞侧偏移）

不依赖训练数据标注，可解释、可校准、可扩展（在 `js/data.js` 里照格式加穴即可）。

```
┌────────────┐   33/21/478 关键点   ┌──────────────┐   骨度分寸比例   ┌────────────┐
│ MediaPipe  │ ──────────────────→ │  锚点换算引擎  │ ──────────────→ │ Canvas 叠加 │
│ (端侧WASM) │                     │ js/data.js   │                 │ 实时渲染    │
└────────────┘                     └──────────────┘                 └────────────┘
```

## 🚀 快速开始

**线上使用**：直接访问 [GitHub Pages 地址](https://wegene38.github.io/acupoint-ar/)（需允许相机权限，首次加载约 20MB 模型后会缓存）。

**安装到手机（当 App 用，支持离线）**：

| 平台 | 方法 |
|---|---|
| Android / Chrome、Edge | 打开线上地址 → 页面内点「📲 安装到手机桌面」按钮，或浏览器菜单「安装应用 / 添加到主屏幕」 |
| iPhone / Safari | 打开线上地址 → 底部「分享 ⬆︎」→「添加到主屏幕」（页面会自动显示引导提示） |
| 桌面 Chrome/Edge | 地址栏右侧安装图标 |

安装后从桌面图标启动即为全屏独立 App；首次联网使用一次后，AI 模型与应用全部缓存，之后**无网也能打开**。

**本地运行**（相机 API 要求 `localhost` 或 HTTPS）：

```bash
git clone https://github.com/Wegene38/acupoint-ar.git
cd acupoint-ar
npm start          # 等价于 python3 -m http.server 8080
# 打开 http://localhost:8080
```

**运行测试**（穴位映射算法自检）：

```bash
npm test           # node test/maps.test.mjs —— 用合成关键点校验全部 68 组映射
```

## 📁 项目结构

```
acupoint-ar/
├── index.html            # 页面结构
├── style.css             # 移动优先样式（暗色玉青主题）
├── sw.js                 # Service Worker（离线缓存：壳网络优先 / 模型缓存优先）
├── manifest.json         # PWA 清单（standalone + maskable 图标）
├── icons/                # 应用图标（192/512/maskable/apple-touch）
├── js/
│   ├── data.js           # ⭐ 穴位数据库 + 骨度分寸映射算法（可扩展）
│   └── app.js            # 相机/检测/渲染/交互/拍照/安装引导
├── models/               # 自托管 MediaPipe 模型（face/hand/pose，共 17MB）
├── vendor/mediapipe/     # 自托管 tasks-vision 运行时 + WASM
├── tools/make-icons.py   # 图标生成脚本
├── test/maps.test.mjs    # 映射函数回归测试
└── docs/市场调研报告.md   # 竞品分析与 MVP 定义依据
```

## ➕ 如何新增穴位

在 `js/data.js` 的 `POINTS` 中加一条，用关键点写映射函数即可，测试会自动覆盖：

```js
{
  id: 'st44', code: 'ST44', name: '内庭', pinyin: 'Nèi Tíng', meridian: 'ST',
  regions: ['body'], key: false,
  location: '足背第 2、3 趾间，趾蹼缘后方赤白肉际处。',
  effects: '清胃泻火。常用于牙痛、口臭、便秘。',
  tips: '按揉 1 分钟。',
  map: { body: (c) => c.sides.filter(s => c.vis(31) > 0.4).map(s => lerp(s.an, s.ft, 0.9)) },
}
```
